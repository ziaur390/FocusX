# FocusXLabs engineering instructions

FocusX is a study accountability app for circles of friends. Start at [START-HERE.md](START-HERE.md).

- Work from a task in the [manifest](harness/tasks.json). Read its module links before editing. Keep the diff focused and preserve existing work.
- Each participant owns their goal and result. Every ready participant owes a check-in and a response to a peer. Let participants leave when needed. Keep outcome, peer acknowledgment, and review status separate.
- Enforce room membership and row ownership on the server. Show shared goals and results only to the appropriate room members. Keep personal practice, private notes and optional media in their approved audiences. Keep credentials out of Git and evidence.
- Publish reviewed original or licensed learning materials. Keep exam year and item version with attempts. Individual mistakes and confidence responses stay private by default.
- Run relevant checks from the normal feature entry points. Use the [evidence template](harness/EVIDENCE-TEMPLATE.md) for observed results and unresolved checks. For shared rooms use separate authenticated browser sessions.
- Review retries, expired invitations, delayed actions, reconnection, and eligibility for points.
- Work on a task branch and hand Zia the PR, latest preview, and actual test evidence when available. Zia owns review and merge to main. Follow the [GitHub workflow](docs/GITHUB-WORKFLOW.md).
