# FX-007 · Today's Study and the first MDCAT learning loop

**Prerequisite.** FX-003 protected accounts and personal history.

**Goal.** Deliver one reviewed topic end to end. A student sees a practical task, answers MCQs, gets explanations, and receives a follow-up review.

**Scope.** Web learning views, development migrations, seed content you are authorized to use, tests. Read [M12](../../docs/modules/M12-MDCAT-LEARNING.md) and [learning design](../../docs/MDCAT-LEARNING-DESIGN.md).

1. Define one versioned MDCAT objective and a small reviewed English item set, including a worked example and fresh variants for review. Preserve source and review metadata.
2. Add Today's Study with a time budget, simple task and due-review preview, and the option to reschedule. Link a short focus session or the existing timer where available.
3. Record submitted responses with answer feedback and optional confidence label. Queue a missed or guessed concept for the next study day. Use a different item for later recall when available.
4. Expose one checked practice-quest completion per eligible attempt to FX-005. Keep the ledger owned by M10.

**Verify.** Run relevant web and database checks, then L1–L3 in the [test matrix](../../docs/TEST-MATRIX.md). Use two test accounts to check attempt privacy. Exercise guess handling, duplicate submits, and explicit content versioning.
