# FX-009 · Exam simulator and pacing feedback

**Prerequisite.** FX-007 versioned items and practice attempts. Use reviewed material and evidence of the exam pattern for the selected year.

**Goal.** Deliver one timed mixed set with a clear score, pacing feedback, and a suggested next review.

**Scope.** Mock configuration, released questions, exam view, attempt handling, and private results. Read [M12](../../docs/modules/M12-MDCAT-LEARNING.md).

Start with a shortened mixed set. Support a resumable timer, mark-for-review, and submit on expiry. Derive results on the server and keep answers hidden until submission. Show skipped items, topic gaps, question pacing, and a link to follow-up practice. Build a full mock when reviewed coverage supports a verified year-specific format. Clearly label any demonstration configuration.

**Verify.** Run L4 in the [test matrix](../../docs/TEST-MATRIX.md). Test resume, duplicate submission, expiry, a student with too few items for a topic conclusion, and authorized access to results.
