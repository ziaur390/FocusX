# FX-003 · Personal workspace

**Prerequisite.** FX-001 working authenticated entry and basic room records.

**Goal.** Give a student an editable profile, a daily goal, and their own session history including open accountability actions. Read [web and accounts](../../docs/modules/M06-WEB-ACCOUNTS.md).

**Scope.** Web onboarding, account and dashboard views, Supabase policies and history tests. Build on FX-001's authentication. Add signup, email confirmation, login/logout as needed for the normal flow. Show display name, exam track/year, timezone and study goal. Keep personal records private. Provide an upcoming session and next check-in or peer response on the first dashboard.

**Verify.** Run W1–W3 in the [matrix](../../docs/TEST-MATRIX.md) using separate browser profiles. Check private history and result retries. Capture actual build and test output.
