# FX-010 · Most recommended resource for each MDCAT topic

**Prerequisite.** FX-007 versioned learning objectives, Today's Study, and an authenticated practice flow.

**Goal.** Help a student choose a lecture or notes quickly. Show the most recommended approved resource for the active topic and up to two alternatives.

**Scope.** Web topic and resource views, the link review queue, Supabase recommendations and access checks, and tests. Read [M13](../../docs/modules/M13-RECOMMENDED-RESOURCES.md) and [learning design](../../docs/MDCAT-LEARNING-DESIGN.md).

1. Seed at least three approved resource links for one subject objective, including a YouTube lecture and an original or authorized notes link. Add creator, format, language, length, and normalized identity.
2. Add the **I used this**, **Recommend**, remove, and report actions. Guard recommendation mutations, prevent a second vote from the same account for the same item, and keep identities out of the public API. Filter out unapproved and unpublished resources.
3. Sort by recommendation totals for the active objective and selected filters, with confirmed use count as the first tiebreaker. Show one top result and up to two alternatives. Give no-vote topics a clearly labeled editor pick or empty state.
4. Link the picker from Today's Study and missed questions. Open the publisher's link and preserve the room's countdown and goal. Keep a practice action and a save-for-later choice.

**Verify.** Run C1–C4 in the [test matrix](../../docs/TEST-MATRIX.md). Include retry and duplicate coverage, one link with fewer uses and more recommendations, a limited-language filter, and an unpublished item. Test that a student can open a lecture and return to the active room with the same countdown and goal. Record the actual environments tested.
