# M10 · Game and rankings

**Owns** focus and practice quests, weekly squad challenges, point computation, and personal, friends, and regional boards. [Social game design](../SOCIAL-GAME-DESIGN.md) defines proposed values and eligibility.

Build the ledger from authenticated practice and session events. Use a transaction and unique award key per user and source. Validate the recorded session eligibility, elapsed timer window, and completed self-reported result for focus points. Reject overlapping ranked sessions and duplicate submissions. A squad quest can use completed accountability actions, including honest partial check-ins and responses. The app awards earned points independently of voluntary messages, peer praise, or a personal departure reason.

Default to private scores. Friend boards use accepted relationships and opt-in settings. Regional rankings use the student's chosen alias and province or region, with participation minimum and opt-out. Handle week boundaries and ties consistently.

**Acceptance.** Score retries exactly once. Check daily caps, weekly reset, ties, repeated or overlapping events, and region privacy. A partial or missed outcome stays valid for accountability, and earlier earned points stay in the ledger.
